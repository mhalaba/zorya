# 04-ux/screens

Static HTML mockups (open in a browser; they load `../../02-tokens/tokens.css` and `mock.css`). Renders at 2× in `png/`. They are references for structure, order and treatment; the spec (`../ux-spec.md`) wins where they differ.

- `app-01-horyzont.html` — home at level obserwacja
- `app-02-horyzont-alarm.html` — home at level alarm (inverted card, "Co robić teraz")
- `app-03-zdarzenie.html` — event detail with instructions and the signal timeline
- `app-04-mapa.html` — map with layers, legend, north arrow
- `app-05-sygnaly.html` — sources and their health
- `app-06-zglos.html` — report form
- `app-07-ustawienia.html` — settings, in the dzień theme
- `www-01-landing.html` — the website at 1280 px

Places in the sample data are fictional (Brzegowo, Nadwiśle, Zaborów).
