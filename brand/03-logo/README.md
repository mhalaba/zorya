# 03-logo

Every file here is generated by `tools/build-logo.py` from one set of numbers (see `logo-manifest.json`). Use the SVGs wherever possible; the PNGs are for places that need rasters.

- `zorya-mark-night.svg` — dark grounds (default). `zorya-mark-day.svg` — light grounds. `zorya-mark-mono.svg` — `currentColor`, for the app header and single-colour uses. All three include the 1u clear space.
- `zorya-wordmark-*.svg` — ZORYA alone. `zorya-lockup-h-*.svg` — the primary lockup. `-h-tagline-` adds *czuwanie świtu*. `zorya-lockup-v-*.svg` — stacked, centred.
- `level-*.svg` — the five status glyphs for the UI, `currentColor`, 32 × 14 box; colour them with `--z-status-*`.
- `app-icon.svg` + PNGs (1024, 512, 192, 180), `app-icon-maskable-512.png` (mark inside the safe zone).
- `favicon.svg`, `favicon-32.png`, `favicon-16.png`.
- `og-image-1200x630.png` (+ `.svg`), `avatar-1000.png`.
- `logo-sheet.png` — contact sheet for review.

Minimums: mark 16 px / 6 mm, horizontal lockup 120 px / 30 mm, vertical 96 px / 24 mm. Never rotate, stretch, recolour outside the palette, add a shadow or glow, or put the mark in a circle or rounded tile.
