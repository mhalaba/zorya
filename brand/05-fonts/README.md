# 05-fonts

Atkinson Hyperlegible Next (UI, headings, wordmark) and Atkinson Hyperlegible Mono (times, numbers, IDs, the descriptor). Variable weight 200–800; use 400, 500, 700, 800. SIL Open Font License 1.1 — `OFL.txt`. Source: the fontsource builds of the Google Fonts release (v5.3.0).

Two subsets per style: `latin` and `latin-ext`. **The Polish glyphs ą ć ę ł ń ś ź ż are in `latin-ext`** — load both with `unicode-range`, exactly as `02-tokens/tokens.css` does. Self-host; do not link Google Fonts.
